# Tomos — OpenCode tools for writers

EPUB production, GitHub backups, and writing tools as OpenCode plugins.

## Quick start

Copy the `.opencode/` folder into your book project, or add to your `opencode.json`:

```json
{
  "plugin": ["./.opencode/plugins/epub-editor.ts"]
}
```

## Tools

- **epub-editor** — Create and edit EPUB2 ebooks via calibre's polish API (12 tools)
- **tomos-backup** — Versioned GitHub backups for book projects

## Skills

- **epub-editor** — Full calibre polish API reference for the AI agent. Includes verified workflow for building EPUBs from chapter markdown files.
