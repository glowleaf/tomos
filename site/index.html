How to install

Step 1 — Download OpenCode

Go to georgesaoulidis.com/opencodedownload.

On that page, look for "OpenCode Desktop (Beta)". Click the Download button for your computer:

• Windows → click "Windows (x64)" Download
• Mac → click "macOS (Apple Silicon)" or "macOS (Intel)" Download
• Linux → click "Linux (.deb)" or "Linux (.rpm)" Download

Run the installer you just downloaded. OpenCode will open when it's done.

Step 1.5 — Download Calibre

The EPUB tools need Calibre. Download and install it from calibre-ebook.com/download. Pick the version for your operating system.

Step 2 — Download the Tomos file

Click the big green button below to download a small file called opencode.json.

⬇ Download opencode.json

Your browser will save a file called opencode.json to your Downloads folder.

Step 3 — Move the file

Take the opencode.json file from your Downloads folder and move it into your book's folder (the one where you keep your manuscript chapters).

If you don't have a book folder yet, create a new empty folder anywhere on your computer and put the file there.

Important: Make a backup of your work first. Only work in a fresh directory with copied files.

Step 4 — Open in OpenCode

Open OpenCode (the app you installed in Step 1). It will ask you to point it to a folder. Choose the book folder where you put the opencode.json file.

That's it. Tomos is installed. You can ask OpenCode to create an EPUB, back up your book, or help with publishing.

What Tomos does

📱 EPUB from your manuscript

Tell it to create an EPUB from your chapter files. It builds the book with proper metadata, cover, and table of contents. Ready to upload.

📐 Smashwords-compliant formatting

Produces EPUBs that pass Smashwords Premium Catalog requirements. No rejections.

💾 Instant GitHub backup

Tell it to back up your book. It creates a git repo, commits everything, and pushes to GitHub. One sentence.
